# 指标口径参考

金额为整数欧元；平均值四舍五入到整数欧元，比例和变化率四舍五入到两位小数。单位、分母、覆盖和不可用状态以工具结果为准。

- 经营日是营业或提前休息；休息、未统计与未录入分别报告。未统计金额和数量为未知，不贡献经营数值或均值分母。
- 有台账日期数=已统计+未统计；已统计=经营日+休息；区间自然日=已统计+未统计+未录入。金额合计只表示已知部分，无已统计台账区别于真实零值。
- 月度总收入由所选日的每日台账营业额与重叠开票月份的已确认公司结算收入组成；年度由各月汇总。无已统计台账不表示完整零收入，已确认结算可独立存在。
- 公司结算收入按开票月份归属，不按确认日期归属；部分月份查询也纳入整笔已确认金额。
- 关闭公司结算业务后，历史已确认收入仍计入统计；待到账应收款不计入收入。
- 日/周台账、台账均值和洗车数量不摊公司结算；仅查询这些指标时不读取结算。部分月份说明实际台账范围和涉及的开票月份，同月的多个日期片段不能重复累计同月结算。
- 经营日均台账营业额仅按经营日计算，不含公司结算收入。
- 月度日均收入只对完整自然月或本月至今定义，本工具不返回任意局部日期或多个自然月区间的这一均值。
- 平均每车收入仅使用同时记录洗车数量的经营日的台账收入除以这些日期的洗车数量，不含公司结算。
- 洗车数量关闭、没有记录或合计为零时平均每车收入不可用；部分覆盖须说明覆盖经营日数。
- 分组按目录允许的日、周、月、收入分类、记录天气、星期及组合执行。极值、排名和汇总按完整匹配集合计算，top_n只是明确选择的排名结果，不把前几行当全期数据。
- 收入构成保留计入营业额的历史分类快照、未分类营业额和已确认公司结算；分类金额/占比明确分母。其他数据不计入总收入，也不等同于成本或利润。
- 当前周/月默认与上期同进度比较；完整周期比较完整范围，精确日期优先。双方使用同源、同筛选、同指标，差额与变化率由后端提供，不用calculate重算。
- 零基期、无可统计台账、数量零和关闭指标分别处理。基期大于零而当前无可统计台账时变化率不可用，当前有真实已知零时可以合法为-100%。
- 结束日期超过门店当地今天时截到今天，明确 requested_range 与实际 range。
- 集中清点金额只记清点当天；解释其覆盖时段使用事件或上下文证据，保留此前未统计状态。
