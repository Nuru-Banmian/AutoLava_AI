# 指标口径参考

金额为整数欧元；平均值四舍五入。

- 经营日是营业或提前休息；休息与未录入分别报告，不将缺失数据补零。
- 总收入由所选日的每日台账营业额与重叠开票月份的已确认公司结算收入组成。
- 公司结算收入按开票月份归属，不按确认日期归属；部分月份查询也纳入整笔已确认金额。
- 关闭公司结算业务后，历史已确认收入仍计入统计；待到账应收款不计入收入。
- 经营日均台账营业额仅按经营日计算，不含公司结算收入。
- 月度日均收入只对自然月定义，本工具不返回局部日期区间的这一指标。
- 平均每车收入仅使用同时记录洗车数量的经营日的台账收入除以这些日期的洗车数量，不含公司结算。
- 洗车数量关闭、没有记录或合计为零时平均每车收入不可用；部分覆盖须说明覆盖经营日数。
- 结束日期超过门店当地今天时截到今天，明确 requested_range 与实际 range。
