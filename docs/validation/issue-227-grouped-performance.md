## 结果与口径

现有公开分析响应的星期、天气分组新增 `operating_day_count`，金额继续使用完整每日台账营业额合计除以经营日数量，以 `ROUND_HALF_UP` 返回整数欧元。营业和提前休息参与，休息排除，公司结算不参与分组。既有星期响应仍只返回有样本的组，页面补齐周一至周日；零样本显示“— / 0 天”，真实零营业额显示“€0”。

天气按既有生成契约中的 28 类固定排列，仅显示有样本类别。兼容类别位于规范类别之后；历史未规范天气随后，“未记录”始终最后。历史天气仍通过既有历史判定归组，缺少记录天气不会丢弃经营日金额和样本。所有图表继续共享一个公开分析查询。

根据开发期间用户关于信息密度的反馈，分析区缩小间距和内边距，趋势图由 256px 调整为 192px，日历日期格由至少 76px 调整为至少 60px。星期 / 天气金额和样本数在同一行常驻显示，常规行实际 28px；独立读数选择入口保持 44px，支持鼠标选择、键盘和触摸打开。电脑两卡共享标题、内容和底部轨道；手机自然高度，无假行或内部滚动。
