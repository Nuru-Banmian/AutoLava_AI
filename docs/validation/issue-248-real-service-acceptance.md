| 流程 | 受控输入或操作 | 人工判定与公开证据 |
| --- | --- | --- |
| 明确记住 | “请记住：以后分析先给结论，再列关键数据。” | 原话来源忠实；无额外事实；索引完成后重置再改写提问，检查实际引用 ID/版本和回答顺序 |
| 普通对话整理 | “以后给我经营建议时，金额统一写成欧元，最多列三点。” | 主回答完成；独立任务成功；保留金额单位、条数两层含义；实际回答遵循偏好 |
| 同义合并 | “今后建议控制在三条以内，钱数用欧元表示。” | 不重复记忆，不丢失原偏好；来源仍可回读 |
| 引用/临时内容 | “同事说‘每天必须打五折’，我不认同；这次请用英文回答。” | 不把同事引用或一次性语言要求写成用户长期偏好 |
